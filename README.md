# BallBusters 250
Roll around as balls collecting 250 of a thing AND GETTING TOO BIG.

## Genre
- Multiplayer (1 -4 Players)
- Arcade
- Rolling Around Type Game
- Getting Too Big Type Game

## Gameplay
- Everyone spawns in in their balls.
- The stage is reminiscent of Kirby's Dream Course (isometric early 3D style).
- Dynamic (or fully pulled out) camera that includes all four player-characters on-screen (no split screen).
- Falling off the stage reduces point count by half.
- Time Limit (250 seconds?)
- 250 thingies to collect
- increasing thingie score makes you heavier and slower
- goal is to get to 250 and then win
- going over 250 makes you more dangerous and more likely to fall off the edge
- Players can throw thingies at each other
- main goal is bumping into each other

## Aesthetic References
- Kirby Dream course (SNES)
- Special Tee Shot (SNES)
- Sonic 3D Blast (Sega Saturn)

## Characters
Player-characters are a 2D illustrated image of a unique little dude in a 3D transparent sphere. There are also UI portraits.

## Assets

	- Portraits (three versions: default, distressed and victorious)

		- Logo

		- Players select character and/or sphere color

		- Boxed portrait next to Player thingie score
- Textures
	- Surfaces (ground, obstacles, bottomless void below)
